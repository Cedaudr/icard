# iCard

A responsive React card built with Tailwind CSS and shadcn/ui.

## Features

- Place image and location title
- Card headline and description
- Left-aligned content
- Call-to-action button
- Responsive layout

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Technologies

- React
- Vite
- Tailwind CSS
- shadcn/ui

## Build

```bash
npm run build
